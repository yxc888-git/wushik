# 五十K · 河南（郑州）版

两副牌（108 张）、4 人**各管各的（不打对家）**的「全副五十K」扑克游戏。
郑州及河南周边流行玩法，纯前端实现，**单机即玩，联机零服务器成本**。

- 单机：**3 / 4 / 5 人可选**（1 人 + 2~4 个电脑对手，AI 自动出牌）
- 联机：**默认走免费公共 MQTT 信道（WebSocket over 公共 Broker），不用自己买服务器**
- 升级：以后有钱了，把 `server/` 传到任意一台云主机，游戏代码一行不改就能切到自建服务器

## 一、怎么玩（玩法速览 · 郑州版）

- **牌**：两副牌共 108 张（含大小王）。4 人各 27 张（3/5 人局按人数均分，余牌轮发）。
- **阵营：各管各的（不打对家）**。谁先出完谁名次靠前，只管自己赢。
- **分牌**：5 = 5 分、10 = 10 分、K = 10 分；两副牌共 **200 分**。一圈牌谁最后压住，桌面上的分就归谁。
- **五十K**：5+10+K 三张成套，**同花色为正五十K（大）**，混花色为副五十K（小）。
- **牌型**：单 / 对 / 三张 / 五十K / 炸。**没有顺子、连对、三顺、飞机，也不能三带一/三带二（不能带牌）**——论大小就是跑得快式"大压小"。
- **炮（炸弹家族）**大小顺序（郑州版，用户逐条确认）：
  `四王 > 4张炸（黑炸>红炸，同色比点数：2>A>K…） > 正五十K（黑♠>红♥>方♦>梅♣） > 副五十K`
  - **炸弹只有 4 张**：4 张同点必须同色——全红（♥♦）或全黑（♠♣）——才算炸；
    **混色 4 张不算炸，5 张/6 张…同点也不算炸**，都只能当散牌正常出（四王除外）。
  - **黑炸 > 红炸**（同点数时黑占先）；点数仍主导：红 2 炸压黑 A 炸。
  - **双大王 / 双小王只是普通对子，压不过五十K**；只有 4 张王（四王）才是最大的炮。
- **见张乎（强制出牌）**：跟牌时手里**只要还有能压过去的牌（含炮），就必须出，不能过牌**（可在规则面板关掉）。
- **接风**：我的大（没人压得上）→ **赢家继续出**；只有赢家把牌**全部走光**、最后一手没人压时，才轮到下手（下家）接风领出。
- **发牌权**：第一局**掷骰子**随机定首发；之后每局由**上一局头游**先出牌。
- **结束 & 结算（交公粮）**：**除末游外全部出完**即结束。
  - **末游（最后一名）交 30 分 → 给头游（第 1 名）**
  - **三游（倒数第二）交 10 分 → 给二游（第 2 名）**（4 人及以上；3 人局只有末游交）
  - **末游手里剩的分牌（5/10/K）按 2 倍结算**：双倍扣末游、给头游（倍数可设，0=关）。
  - 每家最终总分 = 自己抓到的分 + 公粮（正为收、负为交）。
- **算输赢**：交完公粮后**按总分排名**（分最多第一，依次往下）；头游总分达到门槛（默认 **40**，可设）即算**赢方**。

> 规则差异全部收敛在 `src/core/rules.js`，想换地区打法（如三张算炮、简化版、甚至切回对家团队制）改一处预设即可。

## 二、启动方式

### 1. 单机（最省事，双击即可）

双击根目录的 **`启动游戏.bat`**（它用自带 Node 起本地服务并自动开浏览器）。
或手动：

```bash
node serve.js            # 默认 8080 端口
# 或指定端口： node serve.js 9000
```

然后浏览器打开 `http://localhost:8080`，点「单机版」。

> 为什么要用本地服务而不是直接双击 index.html？浏览器禁止 `file://` 加载 ES Module，
> 所以必须有个本地 http 服务。本机零依赖，Node 原生 `http` 即可。

### 2. 联机（免费，不用买服务器）

默认方案走**公共 MQTT Broker（WebSocket 连接）**，零成本。**去中心化**：没有房主当服务器，
四台设备各自连到同一个免费公共频道，按同一副牌（同一 seed）本地演算，只同步"谁出了什么"。

1. 主机（建房的人）和朋友们都在自己设备（电脑/手机）上按「第 1 步」打开游戏页面。
2. 主机点「联机版」→「创建房间」，得到一个 **6 位房间号**；点「复制邀请链接」把带房间号的链接发给朋友。
3. 朋友点开链接 → 自动填好房间号 → 输个名字点「进去」即可加入（不用手动抄房间号）。
4. **4 人齐自动开局，不用谁点开始**；万一第 4 人迟迟不来，房主在 3 人时也能手动「开始游戏」。
5. 各端用同一副牌本地演算，不需要服务器做权威仲裁，所以免费信道也能玩。

信道切换：进房前可换公共 Broker（EMQX / HiveMQ / Mosquitto 公共测试节点），
代码里列表在 `src/net/mqtt.js` 的 `MQTT_BROKERS`，实测三个都可用（Mosquitto 延迟最低 ~180ms）。

### 3. 装到手机 / 打 APK（零成本）

游戏是 **PWA（渐进式 Web 应用）**，已带 `manifest.json` + `sw.js` 离线缓存 + 图标。两种上手机方式：

- **最简单（推荐，不用打 APK）**：把游戏托管到一个 **公网 HTTPS 网址**（见下方「免费托管」），
  手机 Chrome 打开 → 点菜单「安装应用 / 添加到主屏幕」→ 桌面出现全屏图标，体验和 App 一样，
  离线也能开单机。朋友同理，发链接即可。
- **要 .apk 安装包**：用 [PWABuilder](https://www.pwabuilder.com/) 输入那个 HTTPS 网址 → 一键生成 Android `.apk`，
  发给朋友直接安装（需手机允许"未知来源"安装）。

> 注意：Service Worker / PWA 只在 **HTTPS 或 localhost** 下生效；`file://` 和纯 http 局域网地址无法安装。

#### 免费托管到公网 HTTPS（二选一）

- **GitHub Pages（最省心，持久免费）**：把 `wushik` 整个目录推到 GitHub 一个仓库，仓库设置里开 Pages
  （分支 `main` / 根目录），几分钟后拿到 `https://<用户名>.github.io/<仓库>/` 这种永久网址。
- **Cloudflare Pages / Netlify**：拖文件夹即部署，同样免费给 HTTPS 网址。

拿到网址后，联机照常走免费公共 Broker，朋友打开网址就能一起打——**全程不花一分钱服务器钱**。

### 4. 升级到有服务器（将来有钱了）

买台最便宜的云主机（几十块/年），把整个 `wushik` 文件夹传上去：

```bash
node server/server.js            # 联机转发 + 顺便托管网页，端口 8787
# 或 node server/server.js 9000
```

朋友们打开：`http://你的公网IP:8787/?server=ws://你的公网IP:8787`
网页和联机都走这台机器，游戏层代码**零改动**（传输层热插拔，`src/net/ws.js` 与 `mqtt.js` 接口一致）。

## 四、核心设计：为什么能"免费联机"

1. **确定性引擎**：给定 `seed` + 动作序列，各端演算结果**完全一致**。
   联机时每个客户端只广播"我（座位 X）出了这手牌"，收到方在自己本地用同一引擎复现，
   不需要服务器保存权威状态 → 服务器（或免费 Broker）只做消息转发。
2. **三层传输抽象**（游戏逻辑完全不关心用哪层）：
   - `LocalTransport`：单机，AI 出牌，不走网络。
   - `MqttTransport`：默认联机，免费公共 MQTT Broker（WebSocket），零服务器成本。
   - `WsTransport`：自建服务器，URL 带 `?server=ws://...` 一键切换。
3. **自写极简组件**：`mqtt.js` 里手写 MQTT 3.1.1 帧编解码；`server.js` 里手写 WebSocket
   握手 + 帧编解码 + 房间管理。两个文件都**零第三方依赖**，丢到任意 Node 环境就能跑。

## 六、改规则

所有可调项集中在 `src/core/rules.js` 的 `PRESET_HENAN`（默认河南郑州）：

| 字段 | 含义 | 默认 |
|---|---|---|
| `deckCount` | 副数 | 2 |
| `handSize` | 每人手牌 | 27 |
| `seatCount` | 座位数 | 4 |
| `mode` | 玩法阵营：`individual` 各管各的 / `team` 对家配合 | individual |
| `mustBeat` | 见张乎：能压必须出 | true |
| `penalty3rd` | 第 3 名（三游）交公粮 | 10 |
| `penaltyLast` | 第 4 名（末游）交公粮 | 30 |
| `bombMinCount` | 几张算最小炸弹 | 4 |
| `bombSameColor` | 4 张炸须同色（全红/全黑，黑>红） | true |
| `trioIsBomb` | 三张是否算炮 | false |
| `firstDealBy` | 首局领出方 | heart3 |
| `jiefeng` | 下手接风（打不住→下家领出） | true |

也内置 `PRESET_TRIO_BOMB`（三张算炮）、`PRESET_SIMPLE`（简化版），在规则面板里可切换。

## 七、已知边界

- 公共 MQTT Broker 是别人家的，**稳定性随缘**，只适合朋友小范围玩；正经长期要玩就上自建 `server.js`。
- 联机是"房间制"，建房者断线房间就散，没有断线重连。
- 网页与联机消息目前没做加密，公网自建服务器建议套一层 HTTPS/WSS（反向代理即可）。
